# Student Performance Dashboard – Power BI

## 1. Project Overview

The Student Performance Dashboard is an interactive data visualization project developed using Microsoft Power BI. The dashboard provides a clear overview of student academic performance through key performance indicators (KPIs), charts, and interactive filters. It helps users understand student scores and explore performance across different categories.

## 2. Project Objectives

- Analyze students' academic performance in Mathematics, Reading, and Writing.
- Display average subject scores and overall pass percentage.
- Compare student performance across different subjects.
- Visualize the distribution of students by overall result.
- Provide interactive filters to analyze specific student groups.
- Present data in a clear and understandable dashboard.

## 3. Tools and Technologies Used

- **Microsoft Power BI Desktop:** For dashboard development and data visualization.
- **Power BI Visualizations:** For presenting student performance information.
- **Interactive Slicers:** For filtering and exploring the report data.

## 4. Operations Performed in Power BI

### 4.1 Dashboard Creation
Created a report page titled **STUDENT PERFORMANCE DASHBOARD** and arranged the KPI cards, charts, and slicers in a single dashboard layout.

### 4.2 KPI Cards
Created four card visuals to display important performance indicators:

- Average Math Score
- Average Reading Score
- Average Writing Score
- Overall Pass Percentage

These cards provide a quick summary of student performance.

### 4.3 Clustered Column Chart
Created a clustered column chart to compare student scores across subjects. This visualization makes it easier to understand differences in academic performance.

### 4.4 Donut Chart
Created a donut chart to display the distribution of students by overall result. It helps users understand the proportion of students in different result categories.

### 4.5 Interactive Slicers
Added slicers for the following fields:

- Subject
- Gender
- Race/Ethnicity
- Lunch
- Test Preparation Course

These slicers allow users to filter the dashboard and explore student performance based on selected categories.

### 4.6 Dashboard Formatting
Formatted the dashboard using a clear title, KPI cards, charts, and slicers. Organized the visuals to improve readability and make the report easier to understand.

## 5. Key Features

- Interactive student performance analysis.
- Summary cards for important performance indicators.
- Subject-wise score comparison.
- Overall result distribution visualization.
- Multiple slicers for filtering student data.
- User-friendly dashboard layout.

## 6. Insights from the Dashboard

The dashboard helps users explore average scores in Mathematics, Reading, and Writing, compare performance across subjects, and examine overall result distributions. Users can also analyze how the displayed results change when filtering by gender, race/ethnicity, lunch type, test preparation course, or subject.

## 7. How to Use the Dashboard

1. Open the Power BI file using Microsoft Power BI Desktop.
2. Navigate to the Student Performance Dashboard report page.
3. Review the KPI cards to understand the performance summary.
4. Analyze the column chart and donut chart.
5. Use the slicers to select different categories.
6. Observe how the displayed visuals change according to the selected filters.
